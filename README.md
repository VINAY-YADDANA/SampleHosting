# SampleHosting

## Overview
SampleHosting is a lightweight, open‑source web hosting platform designed to simplify the deployment of static and dynamic web applications. It provides an intuitive interface, automated SSL provisioning, and seamless integration with popular CI/CD pipelines.

## Installation
1. **Prerequisites**
   - Docker >= 20.10
   - Docker Compose >= 2.0
   - Git
2. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/samplehosting.git
   cd samplehosting
   ```
3. **Start the services**
   ```bash
   docker compose up -d
   ```
   The platform will be available at `http://localhost:8080`.
4. **Configuration**
   - Edit `config.yaml` to adjust domain settings, storage paths, and authentication methods.
   - Run `docker compose restart` after changes.

## Usage
### Deploy a static site
```bash
# Inside your project directory
git init
git remote add origin https://github.com/yourusername/your-static-site.git
samplehosting deploy --path . --domain example.com
```
The CLI will push your files to the hosting server and automatically request a Let's Encrypt certificate.

### Manage applications via UI
1. Open `http://localhost:8080` in a browser.
2. Log in with the admin credentials defined in `config.yaml`.
3. Use the dashboard to add new sites, view logs, and configure environment variables.
